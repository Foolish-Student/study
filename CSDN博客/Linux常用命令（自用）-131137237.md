# Linux常用命令（自用）

## 基础命令

```cpp
touch 		创建一个文件
makedir 	创建一个文件夹
gedit		使用图形界面打开一个文本文件
```

## Vim

```cpp
gg		光标移动到文档的首行
G		光标移动到文档的尾行
u		撤销
ctrl-r	恢复
y		复制
p		粘贴到光标后
P		粘贴到光标前
/abc	从当前光标向前查找
?abc	从当前光标向后茶渣
n		向同一方向重复上一次的查找
N		反向重复上一次的查找指令
:%s/被替换文本/替换文本/g	全局替换所有
```

## C++相关

```cpp
g++ first.cpp -o first		C++编译
```
