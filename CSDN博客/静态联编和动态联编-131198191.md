# 静态联编和动态联编

## 静态联编和动态联编

静态联编就是在编译的时候就已经确定了调用哪个函数，动态联编就是在运行期间才能确定调用了哪个函数。下面实践一下！

## 静态联编

动态联编调用函数是依靠虚函数表的，那么我们把虚函数表去掉，看一下函数是否还能运行。

```cpp
#include <iostream>
class Base
{
public:
	Base()
	{
		memset(this, 0, sizeof(Base));
		std::cout << "Base()" << std::endl;
	}
	virtual void virFun() { std::cout << "virFun" << std::endl; }
	void Fun() { std::cout << "Fun" << std::endl; }
};
int main()
{
	Base b1;
	b1.virFun();
	b1.Fun();
	return 0;
}
```

在构造函数中，使用memset把vptr的值清空掉，这样它就调用不到虚函数表了，然后再去调用虚函数，看到执行结果：  
![在这里插入图片描述](./image/937ec503160118454af3ca84.png)  
正常执行是没有问题的，他不是一个多态，所以是静态联编。

## 动态联编

多态都是使用的动态联编，将代码进行一个简单的改造

```cpp
#include <iostream>
class Base
{
public:
	Base()
	{
		memset(this, 0, sizeof(Base));
		std::cout << "Base()" << std::endl;
	}
	virtual void virFun() { std::cout << "virFun" << std::endl; }
	void Fun() { std::cout << "Fun" << std::endl; }
};
int main()
{
	Base *b1 = new Base();
	b1->virFun();
	b1->Fun();
	return 0;
}
```

这段代码是跑不通的，会报异常，因为在堆取创建是一个多态但是在构造函数中把虚函数表给清空了，找不到vptr了  
![在这里插入图片描述](./image/a5eb2195f7a5d588ee3a229a.png)  
把memset注释掉，再来运行，就成功了

### 引用实现动态联编

除了指针可以实现动态联编，引用也可以

```cpp
#include <iostream>
class Base
{
public:
	Base()
	{
		memset(this, 0, sizeof(Base));
		std::cout << "Base()" << std::endl;
	}
	virtual void virFun() { std::cout << "virFun" << std::endl; }
	void Fun() { std::cout << "Fun" << std::endl; }
};
int main()
{
	Base *b = new Base();
	Base& b1 = *b;
	b1.virFun();
	b1.Fun();
	return 0;
}
```
