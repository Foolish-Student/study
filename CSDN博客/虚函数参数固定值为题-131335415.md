# 虚函数参数固定值为题

## 虚函数参数固定值问题

这里其实是一个大坑，在之前写demo的时候就遇到过；在虚函数中给变量一个固定值，然后多态创建一个对象，结果参数的定值是父类的。

## 代码

```cpp
#include <iostream>
#include <cstdio>

class A
{
public:
	A(){}
	virtual void AFun1(int i = 10)
	{
		std::cout << "A:AFun1 i = " << i << std::endl;
	}
};

class B : public A
{
public:
	B(){}
	virtual void AFun1(int i = 20)
	{
		std::cout << "B:AFun1 i = " << i << std::endl;
	}
};

int main()
{
	A *a = new B();
	a->AFun1();
	B *b = static_cast<B*>(a);
	b->AFun1();
	B b2;
	b2.AFun1();
	b2.A::AFun1();
	return 0;
}
```

一般来说会以为输出的是：

```cpp
B:AFun1 i = 10
B:AFun1 i = 20
B:AFun1 i = 20
A:AFun1 i = 10
```

实际输出

```cpp
B:AFun1 i = 10
B:AFun1 i = 20
B:AFun1 i = 20
A:AFun1 i = 10
```

很奇怪，对不对，确实很奇怪！

## 动态类型和静态类型

这里需要引入动态类型和静态类型才能解释清楚这个问题

### 什么是动态类型？

就是运行的时候才可以确定的

### 什么的静态类型？

就是编译的时候就已经确定了

### 对main函数中的代码进行分析

```cpp
int main()
{
	// a是一个静态类型 ，它的动态类型是B*
	A *a = new B();		
	a->AFun1();
	//b是一个静态类型，它的动态类型是A*
	B *b = static_cast<B*>(a);
	b->AFun1();
	//b2是一个静态类型
	B b2;
	b2.AFun1();
	b2.A::AFun1();
	return 0;
}
```

虚函数的缺省参数是根据静态类型去绑定的，但是调用虚函数是看的动态类型。

## 总结

当虚函数有省略参数，并且重写了，需要根据静态类型和动态类型来区分省略参数的绑定时机和虚函数的调用  
尽量避免重写父类的虚函数，这样可以避免该问题  
通常情况下静态类型在等号的左边
