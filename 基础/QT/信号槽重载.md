# Qt 信号槽重载

信号或槽存在同名重载时，直接写 `&类名::函数名` 无法确定具体版本，需要显式指定参数类型。下面统一演示无参和 `int` 参数两个版本。

## 示例声明

```cpp
#include <QObject>

class Sender : public QObject {
    Q_OBJECT
signals:
    void changed();
    void changed(int value);
};

class Receiver : public QObject {
    Q_OBJECT
public slots:
    void handle() {}
    void handle(int value) { Q_UNUSED(value); }
};
```

下面的连接代码写在函数内，假设已有 `Sender* sender` 和 `Receiver* receiver`。每组写法任选一种，不要重复连接。

## 1. 成员函数指针

通过指针类型选择具体重载，信号和槽分别指定：

```cpp
void (Sender::*signal0)() = &Sender::changed;
void (Receiver::*slot0)() = &Receiver::handle;
QObject::connect(sender, signal0, receiver, slot0);

void (Sender::*signal1)(int) = &Sender::changed;
void (Receiver::*slot1)(int) = &Receiver::handle;
QObject::connect(sender, signal1, receiver, slot1);
```

`void (Sender::*)(int)` 表示：指向 `Sender` 的成员函数，参数为 `int`，返回值为 `void`。这里不能用 `auto` 代替具体类型，否则仍然无法消除重载歧义。

## 2. static_cast

与上面原理相同，直接在 `connect` 中指定成员函数指针类型：

```cpp
// 无参 → 无参
QObject::connect(sender,
    static_cast<void (Sender::*)()>(&Sender::changed), receiver,
    static_cast<void (Receiver::*)()>(&Receiver::handle));

// 有参 → 有参
QObject::connect(sender,
    static_cast<void (Sender::*)(int)>(&Sender::changed), receiver,
    static_cast<void (Receiver::*)(int)>(&Receiver::handle));
```

## 3. QOverload / qOverload

这两种辅助写法用模板参数指定函数的参数类型；无参版本写空的 `<>`，不是 `<void>`。

```cpp
// QOverload：Qt 5.7 起支持，可用于 C++11
QObject::connect(sender, QOverload<>::of(&Sender::changed),
                 receiver, QOverload<>::of(&Receiver::handle));

QObject::connect(sender, QOverload<int>::of(&Sender::changed),
                 receiver, QOverload<int>::of(&Receiver::handle));
```

`qOverload` 更简短，Qt 5 中需要 C++14；Qt 6 项目可直接使用：

```cpp
QObject::connect(sender, qOverload<>(&Sender::changed),
                 receiver, qOverload<>(&Receiver::handle));

QObject::connect(sender, qOverload<int>(&Sender::changed),
                 receiver, qOverload<int>(&Receiver::handle));
```

多个参数按声明顺序写，例如 `qOverload<int, const QString&>(...)`。类型要与选中的重载签名匹配。若只是信号或槽的一侧有重载，只需对那一侧消除歧义。

## 4. lambda 包装槽调用

lambda 内通过实参选择槽的重载，但信号端仍需要指定版本：

```cpp
QObject::connect(sender, qOverload<>(&Sender::changed),
                 receiver, [receiver]() { receiver->handle(); });

QObject::connect(sender, qOverload<int>(&Sender::changed),
                 receiver, [receiver](int value) { receiver->handle(value); });
```

这里把 `receiver` 作为上下文对象，销毁时连接会自动断开。需要转换参数、补充参数或增加逻辑时，这种写法更方便。

## 5. 旧式 SIGNAL / SLOT

通过宏中的签名区分重载，无参写 `()`，有参只写类型：

```cpp
QObject::connect(sender, SIGNAL(changed()), receiver, SLOT(handle()));
QObject::connect(sender, SIGNAL(changed(int)), receiver, SLOT(handle(int)));
```

这种方式在运行时检查连接，缺少编译期类型检查，新代码优先使用前面的写法。

## 参数与调用注意事项

- 有参信号可以连接无参槽，多余的尾部参数会被忽略；无参信号不能直接连接需要 `int` 参数的槽。
- 连接重载时，编译器不会仅凭另一侧的参数自动选择版本，仍需明确指定。
- 发射信号和普通函数调用一样，通过实参选择重载：`emit sender->changed();`、`emit sender->changed(10);`。

```cpp
// 有参 → 无参
QObject::connect(sender, qOverload<int>(&Sender::changed),
                 receiver, qOverload<>(&Receiver::handle));

// 无参 → 有参：用 lambda 显式提供参数
QObject::connect(sender, qOverload<>(&Sender::changed),
                 receiver, [receiver]() { receiver->handle(10); });
```
